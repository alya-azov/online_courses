# Проект по курсу "Базы Данных", весна 2025

## Обзор проекта

Проект представляет собой базу данных платформы для онлайн обучения.
В папке docs находится файл концептуальной, логической и физической моделей базы данных.

Всего будет 8 таблиц:
 - ученики (id, имя, фамилия, почта, телефон, пол, дата регистрации)
 - преподаватели (id, имя, фамилия, почта, краткая биография, id курса, который ведут)
 - курсы (id, название, описание, дата создания, продолжительность в часах)
 - запись на курсы (id, id студента, id курса, дата записи, статус)
 - модули (id, id курса к которому относится модуль, название, описание, порядок следования модуля в курсе)
 - задания (id, id модуля к которому относится задание, название, описание, время на выполнение)
 - сдачи (id, id ученика, id задания, оценка)
 - сертификат об окончании курса (id, id ученика, id курса, дата выдачи, индивидуальный номер сертификата)
